# Proyecto-4-curso-analisis-de-datos.
Proyecto 4: Análisis de Impacto Estadístico e Inferencia para Políticas Públicas (Python).

Realicé un estudio de estadística inferencial para el Ministerio de Educación comparando el rendimiento académico
entre grupos de control y tratamiento en establecimientos de educación escolar.

Apliqué pruebas de hipótesis estadísticas para determinar la significancia de una nueva metodología educativa
utilizando datos estructurados de la plataforma SENCE.
